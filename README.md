# 🎓 ScholarSync — AI Placement & Career Ecosystem

> **Live Working Model**: [https://scholarsyncers.netlify.app/](https://scholarsyncers.netlify.app/)  
> **Database Backing**: Supabase Cloud PostgreSQL  
> **AI Engine**: Google Gemini 3.6 Flash

## 🌟 Overview

**ScholarSync** is an end-to-end AI placement preparation platform designed for college engineering students to accelerate their campus and off-campus recruitment journey.

- 🔗 **Deployment URL**: [https://scholarsyncers.netlify.app/](https://scholarsyncers.netlify.app/)

---

## ✨ Core Features

### 1. 🤖 ScholarSync AI Studio
- **Dedicated 3-Section AI Workspace** with persistent multi-session conversation history.
- **Context-Aware Recommendations**: Automatically ingests candidate target companies, roles, CGPA, and diagnostic scores.
- **Markdown & Code Studio**: Syntax-highlighted code blocks with 1-click clipboard copy.

### 2. 🎙️ AI Mock Interview Simulation
- 4-question interactive company-specific simulation (General, Technical, Flagship Project, Architecture).
- Keyword analysis and metric-based scoring.

### 3. 🎯 AI Gap Analyzer & Readiness Index
- Multi-dimensional skill breakdown (Coding, Aptitude, Technical, Communication, Resume, Interview).
- Dynamic weighted readiness score calculated against target tier-1 companies.

### 4. 📄 ATS Resume AI Reviewer (PDF)
- Client-side PDF text extraction via PDF.js.
- Instant scoring, quantified metric detection, and peer community feedback board.

### 5. 🎬 AI Reels & Video Lessons
- Micro-learning placement reels and curated long-form lessons.
- Bookmarking and cloud persistence via Supabase.

### 6. 📝 Community Placement Blog
- Peer interview experiences, salary insights, and placement guides with real-time cloud sync.

## 🛠️ Tech Stack

- **Frontend**: Single Page Application (React 18, Tailwind CSS, Babel Standalone)
- **Cloud Database**: [Supabase](https://supabase.com) (PostgreSQL, Row Level Security, Realtime)
- **AI Models**: Google Gemini 3.6 Flash
- **Hosting & CI/CD**: Netlify

## 💻 Local Setup & Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/your-username/scholarsync.git
   ```
2. Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Brave):
   - No complex installation or build step required!
3. (Optional) Run the lightweight Node.js server:
   ```bash
   node server.js
   ```
